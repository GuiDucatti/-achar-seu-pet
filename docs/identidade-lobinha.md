# Identidade visual da Lobinha

A interface usa como referencia as cores da Lobinha, cachorra caramela e branca com olhos azuis:

- caramelo dourado `#C47A3C` para a identidade principal;
- caramelo claro `#E7B77D` para detalhes suaves;
- creme `#FFFDF9` e branco para superficies;
- marrom `#3B2A24` para textos;
- azul-gelo `#5EA9D6` e azul profundo `#347EA8` para mapa, foco e interacoes;
- marrom rosado do focinho `#8E5A52` como referencia secundaria.

O frontend tambem usa `lucide-react` para icones consistentes e acessiveis e `framer-motion` para transicoes curtas nas rotas, cards e estados vazios.
